# Roadmap

## [0.4.0 hardening](https://github.com/display-design-studio/vite-plugin-shopify-theme/issues/25)

- Setup wizard for new and existing Shopify themes.
- Coordinated Vite and Shopify development command.
- Canonical default import and VitePress documentation.
- Post-RFC hardening: CLI failure coverage, packed executable verification, and protected real-Shopify E2E through the public `dev` command.
- Safety-first documentation for ownership, recovery, multi-theme layouts, external tunnels, frameworks, and operational diagnostics.

Release remains gated on the compatibility matrices, protected Shopify E2E, Theme Check, packed-package contract, and final publication verification.

Release completion rolls up to the [adoption and 1.0 roadmap](https://github.com/display-design-studio/vite-plugin-shopify-theme/issues/1).

Tunnel management and deployment remain out of scope.
