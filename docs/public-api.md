# Public API

```ts
import shopify, { shopifyTheme } from '@display-studio/vite-plugin-shopify-theme';
```

The default export and `shopifyTheme` are identical; the default import is canonical. Existing named helpers and types remain compatible. The package exports only its root. The `vite-shopify-theme` executable is not a JavaScript subpath API, and the package has zero runtime dependencies.
