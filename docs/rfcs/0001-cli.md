# RFC 0001: Setup and development CLI

- Status: accepted for implementation
- Target: 0.4.0

Publish `vite-shopify-theme init` for conservative scaffolding of new Skeleton projects and existing themes, plus `vite-shopify-theme dev` for coordinated local Vite and Shopify processes. The root JavaScript API remains backward compatible and the package retains zero runtime dependencies.

Setup never converts invalid directories, overwrites incompatible manual configuration, or introduces force mode. Defaults are TypeScript, detected manager or npm, Tailwind, and optional Shopify AI Toolkit skills after a telemetry notice. The CLI scope ends at scaffolding and local development; tunnels and deployment remain out of scope.
